# 自定义 MSPM0G3519 开发板

## 识别条件

当 `.syscfg` 使用 `--device "MSPM0G3519" --package "LQFP-64(PM)"`，且项目被用户说明为自定义 G3519 板时，读取本文件。自定义板的板载资源必须以用户原理图和当前工程为最终依据。

## 不可随意分配的系统引脚

| 引脚 | 功能 | 规则 |
|---|---|---|
| PA2 | 频率精度控制/ROSC | 未确认布线前不要分配给普通外设 |
| PA5、PA6 | 40 MHz HFXT 晶振 | 不得分配给普通外设 |
| PA19、PA20 | SWDIO / SWCLK | 保留调试接口 |
| PA18 | BSL 入口/按键 | 复位时拉高会进入 BSL；任何输出复用前必须确认上电电平 |

## 已知板载资源模板

以下资源适用于仓库当前维护的自定义 G3519 示例，不应自动推断为所有自定义板的真实连接：

| 引脚 | 示例中的资源 |
|---|---|
| PA0、PA1 | 软件 I2C OLED SDA/SCL，带 2.2 kΩ 上拉 |
| PA10、PA11 | UART0 / 板载 CH340 |
| PA27、PA28 | 软件 I2C LSM6DS3 IMU |
| PB6、PB7、PB8、PB9 | SPI1 W25Q128 Flash |
| PB17、PB18 | UART7 无线模块 |
| PB21 | ENTER 按键，低有效 |
| PB22 | 调试 LED，低有效 |
| PB23 | 无线链路状态输入 |
| PB26 | TIMA1 CCP0 WS2812 |
| PB27 | TIMG6 CCP1 蜂鸣器 |
| PA29、PA30 | QEI 编码器 PHA/PHB |
| PA31 | 编码器按键 |

如果用户的自定义板原理图与此表不同，以用户原理图和当前 `.syscfg` 为准；不要直接复制示例引脚。

## 选择引脚的规则

优先排除 PA2、PA5、PA6、PA18、PA19 和 PA20。对于示例中已有的板载资源引脚，只有在用户确认释放对应外设后才能复用。若用户没有提供原理图，不要声称某个未列出的引脚一定空闲。

## 验证要求

修改前确认设备和封装；修改后运行 `python scripts/check_syscfg.py <project-dir>`，检查 HFXT、ROSC、SWD、BSL 和生成文件。板载资源、供电、电平和外部接线必须通过用户原理图或真实硬件验证，不能仅凭本仓库示例推断。
