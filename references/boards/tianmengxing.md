# 立创·天猛星 MSPM0G3507

## 识别条件

当项目明确使用 LCKFB Tianmengxing / 立创·天猛星 MSPM0G3507，或 `.syscfg` 与本板卡资料能够相互印证时，读取本文件。天猛星使用 MSPM0G3507 LQFP-64 封装。

## 板载资源与引脚风险

以下引脚已经连接到板载功能。除非用户明确要求并确认影响，否则不要重新分配：

| 引脚 | 板载功能 | 注意事项 |
|---|---|---|
| PA5、PA6 | 40 MHz HFXT 晶振 | 不得分配给普通外设 |
| PA19、PA20 | SWDIO / SWCLK | 保留调试接口 |
| PA18 | BSL 入口/按键 | 复位时拉高会进入 BSL，不要让外部输出在上电时拉高 |
| PA10、PA11 | UART0 / CH340E | 可用于板载串口通信，不要忽略共享关系 |
| PA27、PA28 | LSM6DS3 IMU I2C | 复用前确认 IMU 是否仍需使用 |
| PB6、PB7、PB8、PB9 | 板载 SPI Flash | 复用前确认 Flash 是否仍需使用 |
| PB17、PB18 | 板载无线模块 UART7 | 复用前确认无线模块是否仍需使用 |
| PB21 | ENTER 按键，低有效 | 注意上拉和按键状态 |
| PB22 | 板载 LED，低有效 | LED 低电平点亮，常用 PWM/ GPIO 示例引脚 |
| PB23 | 无线链路状态输入 | 注意输入默认电平 |
| PB26 | WS2812 RGB，TIMA1 CCP0 | 复用会影响板载 RGB |
| PB27 | 蜂鸣器，TIMG6 CCP1 | 复用会影响板载蜂鸣器 |
| PA29、PA30 | QEI 编码器 PHA/PHB | 可释放，但应先确认编码器是否使用 |
| PA31 | 编码器按键 | 可释放，但应先确认编码器是否使用 |

## 选择引脚的规则

用户询问空闲引脚时，优先选择不在上表中的引脚，并结合当前 `.syscfg`、扩展排针和原理图确认。用户明确指定已占用引脚时，先说明冲突，再根据用户意图请求确认或继续。

## 常见板载外设

天猛星常见板载资源包括 PB22 LED、OLED、LSM6DS3 IMU、WS2812 RGB、蜂鸣器、QEI 编码器、UART0/CH340E 和无线 UART7。依赖这些资源的示例不能直接视为地猛星示例，需要先确认板型。

## 验证要求

修改引脚后至少运行 `python scripts/check_syscfg.py <project-dir>`，检查 HFXT、SWD、BSL 和板载外设冲突。没有实际接入天猛星硬件时，只能报告源码、SysConfig 或编译级别结果，不能声称板级验证完成。
