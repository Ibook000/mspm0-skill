首页安装板卡示例工作流工具FAQ验证

TOOLS

检查工程，记录真实进度。

规则与参考文档可直接阅读；运行辅助脚本时按仓库要求安装 Python 开发依赖。

工具用途
check_syscfg.py静态检查 .syscfg、生成物、工程结构与板卡引脚规则
verify_example.py汇总静态、SysConfig、构建产物、烧录准备和人工硬件状态
list_examples.py读取内置示例 manifest 并列出示例
index_syscfg_examples.py索引本地 TI SDK SysConfig 示例
serial_console.py串口端口列表与收发辅助
ccs_dss_debug.py在对应 CCS 与探针环境中使用 DSS 调试

常用命令

python3 scripts/list_examples.py
python3 scripts/check_syscfg.py <project-dir> --board tianmengxing --json
python3 scripts/verify_example.py examples/led_blink --snapshot --json
python3 scripts/serial_console.py --list

--snapshot 适用于仓库自带的源码快照。阅读 状态含义 后再引用检查结果。
