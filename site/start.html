GET STARTED

安装与快速开始

根目录就是 Skill 本体。先加载规则，再交代芯片、板卡和当前工程。

安装

仓库 README 提供以下 Node.js 安装命令；也可以克隆仓库，将完整目录放入 Agent 的 skills 目录。

npx skills add Ibook000/mspm0-skill
git clone https://github.com/Ibook000/mspm0-skill.git
cd mspm0-skill

手动安装位置包括 Claude Code 的 ~/.claude/skills/mspm0-skill/ 与 Codex 等工具的 ~/.agents/skills/mspm0-skill/。具体以 仓库 README 为准。

给 Agent 的第一个任务

先读取 mspm0-skill/SKILL.md。
当前工程使用 MSPM0G3507、立创·天猛星。
请先确认 .syscfg、生成头文件和板卡引脚占用，再修改 PB22 LED 逻辑。
不要手动修改 ti_msp_dl_config.c/.h。
最后分别报告静态检查、编译、烧录和实板验证结果。

板卡无法确认时，先核对原理图与工程配置，不要把某块板的引脚表套在另一块板上。

运行仓库检查

python3 -m pip install -r requirements-dev.txt
python3 scripts/validate_repo.py
python3 scripts/check_syscfg.py <project-dir> --board tianmengxing --json

上述 Python 命令在克隆的仓库根目录运行。tianmengxing 应换成实际板卡 ID。检查器分析文件与规则，不等于完成构建或硬件实测。
