FAQ

常见问题

本页给出简答，详细步骤与限制见 仓库 FAQ 原文。

mspm0-skill 是 SDK 或 IDE 插件吗？

它是供编程 Agent 使用的规则集，配有 Python 辅助脚本、板卡数据和示例；不能代替 TI SDK、构建工具或实板验证。

为什么不能手改 ti_msp_dl_config.c/.h？

这些文件由 SysConfig 生成。应修改 .syscfg 并重新生成，再从当前生成头文件核对宏名和初始化函数。

没有 ti_msp_dl_config.h 怎么办？

工程可能尚未生成或构建。仓库的源码快照可以用 --snapshot 检查；真实工程需通过对应工具链生成和编译。

天猛星、地猛星和地正星的 LED 一样吗？

不一样。天猛星 PB22 低有效；地猛星 PA14 低有效；地正星 PA14 高有效。核对板卡原理图与 对应规则。

UART 没输出应先查什么？

依次核对时钟、UART 实例、TX/RX 引脚、波特率和格式、CH340 连接、供电及接线。可用 scripts/serial_console.py --list 查端口。

静态检查通过等于硬件可用吗？

不等于。构建、烧录、串口和外设行为都需要分别验证；见 验证状态说明。
