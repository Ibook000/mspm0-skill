TI MSPM0 · AI AGENT SKILL

让 Agent 先读懂板卡和 SysConfig，再修改固件。

mspm0-skill 是面向 Codex、Claude Code 等编程 Agent 的嵌入式开发规则集，配有板卡数据、静态检查工具和示例源码。适用于 MSPM0G3507、MSPM0G3519 与 MSPM0L1306 相关工程。

开始使用 ↗查看 GitHub 源码

从你的问题开始

01 / BOARD

选板卡和引脚

天猛星、地猛星、地正星与自定义 G3519 的规则入口。

02 / CONFIG

改 SysConfig

确认工程、修改 .syscfg、检查生成名称和引脚占用。

03 / EXAMPLES

查可复用示例

GPIO、PWM、UART 与 OLED UI 源码快照及使用边界。

04 / DEBUG

排查常见问题

生成头文件、串口输出、静态检查和硬件验证。

引用时看原始证据

板卡引脚以 boards/*.json 为机器可读来源，Agent 的修改边界以 SKILL.md 为准。静态检查不能证明编译、烧录或实板运行，详见 验证状态。
