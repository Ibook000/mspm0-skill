MSPM0-SKILL / DOCUMENTATION

TI MSPM0 开发手册

给编程 Agent 使用的 TI MSPM0 工程规则、板卡约束和检查工具。覆盖 MSPM0G3507、MSPM0G3519 与 MSPM0L1306，所有结论都回到当前工程、生成文件与板卡数据。

开始使用 ↗查看 GitHub 源码
快速安装
TERMINAL
npx skills add Ibook000/mspm0-skill

从你的问题开始#

01 / BOARD

选板卡和引脚

天猛星、地猛星、地正星与自定义 G3519 的规则入口。

02 / CONFIG

改 SysConfig

确认工程、修改 .syscfg、检查生成名称和引脚占用。

03 / EXAMPLES

查可复用示例

GPIO、PWM、UART 与 OLED UI 源码快照及使用边界。

04 / DEBUG

排查常见问题

生成头文件、串口输出、静态检查和硬件验证。

引用时看原始证据#

板卡引脚以 boards/*.json 为机器可读来源，Agent 的修改边界以 SKILL.md 为准。静态检查不能证明编译、烧录或实板运行，详见 验证状态。
